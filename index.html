Como os Juízes acessam pelo Celular (4G ou Wi-Fi)

A interface de Paddock é 100% responsiva para smartphones. Para que os juízes abram no celular no dia do evento:

  • Opção 1 (Oficial / Recomendada): Suba esta pasta no Cloudflare Pages (ou GitHub Pages) e imprima o QR Code gerado para colar nas pranchetas dos juízes.
  • Opção 2 (Rede Wi-Fi Local): Se o notebook e os celulares estiverem no mesmo Wi-Fi do ginásio, rode npx serve ou python -m http.server 8080 no notebook e abra pelo IP (ex: http://192.168.1.X:8080/paddock/).
